# Sentinel Cyber Security Suite - CS Department Dashboard

React + TypeScript + Vite management dashboard for the Sentinel Cyber Security Suite.

## Run Locally

**Prerequisites:** Node.js 18+

1. Install dependencies:
   `npm install`
2. Copy `.env.example` to `.env.local` and set `VITE_API_URL` to your management server.
3. Run the app:
   `npm run dev`
4. Open http://localhost:3000
